# Design System

## Direction

Astral instrument: an elegant personal observatory where a quiet orbital scene frames concise technical work.

## Palette

- Background: `#141916`
- Surface: `#1b211d`
- Ink: `#eeeade`
- Muted: `#a5aca2`
- Line: `#394038`
- Celestial accent: `#d0a580`

The light theme uses the same green-gray family with dark ink and the same warm accent.

## Typography

- Display: Barlow Condensed for compact, decisive headings.
- Body: DM Sans for reading.
- Mono: system monospace only for small system labels.

## Interaction

- 200–300ms micro-interactions for links, filters and icon controls.
- The 3D orbit, carousel and subtle signal lines pause or simplify for reduced motion.
- Project browsing is driven by category tabs and text search.

## Layout

- One dominant idea per section.
- `1440px` max content width with generous but purposeful whitespace.
- Project content uses alternating editorial layouts; long project lists use filtering instead of default rows.
